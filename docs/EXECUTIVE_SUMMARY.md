# Executive Summary
## SleepFM-Wearable-Health Project

**문서 버전:** 1.0  
**작성일:** 2026년 1월 8일  
**프로젝트 코드명:** SleepFM-Wearable-Health

---

## 1. 프로젝트 개요

### 1.1 프로젝트 비전
SleepFM-Wearable-Health는 **AI 기반 수면 분석 파운데이션 모델(SleepFM)**을 웨어러블 디바이스에 적용하여, 일상 속에서 지속적인 건강 모니터링과 질병 조기 예측을 가능하게 하는 연구 프로토타입입니다.

### 1.2 핵심 가치
- **조기 발견**: 단 하루 밤의 수면 데이터로 130개 이상의 질환 위험을 예측 (C-Index ≥ 0.75)
- **비침습적 모니터링**: 웨어러블 기기를 통한 자연스러운 일상 건강 체크
- **개인화된 건강관리**: 매일 밤 자동으로 업데이트되는 건강 상태 추적
- **접근성 향상**: 병원 방문 없이도 신경퇴행성 질환, 심혈관 질환 등의 조기 위험 신호 탐지

### 1.3 타겟 플랫폼
- **Apple Watch** (watchOS + iOS 앱)
- **Samsung Galaxy Watch** (Wear OS + Android 앱)

---

## 2. 과학적 근거

### 2.1 SleepFM 논문 성과 (Nature Medicine, 2026)
- **데이터 규모**: 65,000명 이상, 총 58만 시간 이상의 PSG(수면다원검사) 데이터로 학습
- **학습 기법**: 대조 학습(Contrastive Learning)을 통한 높은 일반화 성능
- **검증 완료**: 130개 질환에 대해 기존 모델 대비 5-17% 성능 향상

### 2.2 주요 질환 예측 성능 (C-Index)
| 질환 | C-Index |
|------|---------|
| 파킨슨병 | 0.93 |
| 치매 | 0.85 |
| 심근경색 | 0.81 |
| 심부전 | 0.80 |
| 만성 신장질환 | 0.79 |
| 뇌졸중 | 0.78 |

### 2.3 수면 분석 성능
- **수면 단계 분류**: F1 Score 0.70–0.78
- **수면무호흡증 분류**: 정확도 0.87

## 3. 프로젝트 목표

### 3.1 단기 목표 (Phase 1-2)
1. **ML 백엔드 구축**: SleepFM 모델을 웨어러블 데이터에 적용 가능한 API 서비스 개발
2. **모바일/웨어러블 앱 개발**: Apple Watch 및 Samsung Galaxy Watch용 네이티브 앱 개발
3. **핵심 기능 구현**: 수면 단계 분류, 수면무호흡 탐지, 3-5개 주요 질환 위험 스코어 제공

### 3.2 중기 목표 (Phase 3)
1. **통합 테스트**: 공개 데이터셋을 활용한 교차 검증 및 성능 확인
2. **베타 테스트**: 실제 사용자 피드백 수집 및 개선
3. **보안/규제 대응**: 개인정보 보호 설계, 연구용 라벨링, 비진단 고지 구현

### 3.3 장기 비전
- 의료 시스템과의 연계 가능성 탐색
- 클라우드 기반 대규모 데이터 분석 파이프라인 구축
- 글로벌 건강 관리 플랫폼으로의 확장

---

## 4. 주요 기능

### 4.1 백엔드 서비스
- **데이터 전처리**: 웨어러블 신호를 128Hz로 리샘플링, 5초 윈도우 토큰화
- **멀티모달 임베딩 추출**: CNN 토크나이저 + 채널/시간 어텐션 풀링
- **질병 위험 예측 엔진**: Linear/LSTM 기반 CoxPH 헤드로 다중 질환 위험 스코어 산출
- **수면 분석 엔진**: 수면 단계 분류, 무호흡 탐지
- **REST API**: FastAPI 기반 추론 서비스

### 4.2 모바일 앱 (iOS/Android)
- **건강 대시보드**: 수면 분석 결과 및 질병 위험 스코어 시각화
- **주간/월간 리포트**: 장기 트렌드 분석 및 건강 인사이트 제공
- **데이터 동기화**: 워치 데이터 수집 및 서버 전송
- **개인정보 보호**: 로컬 암호화 저장, 사용자 동의 기반 데이터 전송

### 4.3 웨어러블 앱 (watchOS/Wear OS)
- **센서 데이터 수집**: ECG, PPG, 심박수, 호흡률, 가속도 등
- **백그라운드 모니터링**: 수면 중 자동 데이터 기록
- **실시간 알림**: 건강 이상 징후 감지 시 즉각 알림
- **워치페이스 컴플리케이션**: 주요 건강 지표 실시간 표시

## 5. 기술 아키텍처

### 5.1 시스템 구성
```
[웨어러블 기기] → [모바일 앱] → [ML 백엔드 API] → [질병 위험 예측 결과]
     ↓                ↓                ↓
  센서 데이터    데이터 시각화      추론 서비스
  자동 수집       건강 리포트       모델 추론
```

### 5.2 핵심 기술 스택
- **ML/AI**: PyTorch, SleepFM 파운데이션 모델, CNN + Transformer
- **백엔드**: FastAPI, Python 3.10+
- **iOS 개발**: Swift, SwiftUI, HealthKit, Core ML
- **Android 개발**: Kotlin, Jetpack Compose, Samsung Health SDK
- **데이터**: 공개 수면 데이터셋 (SHHS, MrOS, MESA, SSC)

## 6. 기대 효과

### 6.1 의료적 가치
- **조기 발견**: 무증상 단계의 신경퇴행성 질환, 심혈관 질환 조기 탐지
- **예방 중심 의료**: 질병 발생 전 선제적 개입 가능
- **의료 접근성**: 저비용·비침습적 방식으로 대규모 인구 모니터링 가능
- **개인 맞춤형 의료**: 개인별 건강 데이터 기반 맞춤형 건강관리

### 6.2 사회적 가치
- **의료비 절감**: 조기 예방을 통한 치료 비용 감소
- **삶의 질 향상**: 건강 불안 감소, 적시 대응으로 합병증 예방
- **의료 형평성**: 원격 지역, 의료 소외 계층도 건강 모니터링 접근 가능

### 6.3 연구적 가치
- **파운데이션 모델 실용화**: 대규모 AI 모델의 웨어러블 적용 사례 연구
- **데이터 축적**: 실제 웨어러블 데이터 수집 및 검증
- **학술 기여**: 추가 연구 논문 출판 가능성

## 10. 결론

SleepFM-Wearable-Health 프로젝트는 **세계 최고 수준의 수면 파운데이션 모델을 일상적인 웨어러블 기기에 적용**함으로써, 질병 조기 예측과 예방 중심 의료의 새로운 패러다임을 제시합니다.

**핵심 차별점:**
- ✅ 검증된 과학적 근거 (Nature Medicine 논문)
- ✅ 대규모 데이터 기반 파운데이션 모델
- ✅ 비침습적·일상적 모니터링
- ✅ 다중 질환 동시 예측
- ✅ 주요 웨어러블 플랫폼 지원

**즉시 시작 가능:**
- 공개된 모델 가중치 및 코드 활용
- 공개 데이터셋 접근 가능
- 검증된 기술 스택

본 프로젝트는 **AI와 웨어러블 기술을 결합한 차세대 건강관리 솔루션의 첫 걸음**이며, 향후 의료 산업과 개인 건강관리의 표준이 될 수 있는 기술적 기반을 마련합니다.
